ПРОЕКТ TALK LIKE OTHER CHARACTERS — NETLIFY

Это версия именно для Netlify, не для Cloudflare.

Структура:
- index.html, style.css, app.js — сайт
- netlify/functions/rewrite.js — серверная функция ИИ
- netlify.toml — настройки публикации и адрес /api/rewrite

ВАЖНО:
1. При ручной загрузке ZIP через перетаскивание в Netlify серверная функция не будет собрана.
2. Для работы функции подключите папку/репозиторий через GitHub к существующему сайту Netlify, чтобы Netlify выполнил сборку.
3. После публикации добавьте в Netlify переменные окружения:
   AI_API_KEY — секретный API-ключ провайдера
   AI_MODEL — точное имя модели
   AI_BASE_URL — базовый URL API (необязательно; по умолчанию https://api.openai.com/v1)
4. После изменения переменных окружения запустите новое развертывание.

Не публикуйте API-ключ в HTML, app.js или открытом репозитории.
Без настоящего ключа и доступного API модель отвечать не будет.
